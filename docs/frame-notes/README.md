# 프레임 관찰 기록

원작 공개 영상(Extended Gameplay Trailer, 3:52)을 2.5초 간격으로 잘라 **93장을
눈으로 보고** 적은 기록이다. 파일번호 N ≈ (N-1)×2.5초.

| 파일 | 구간 |
|---|---|
| [notes-a.md](./notes-a.md) | 001~024 · 0:00~0:57 |
| [notes-b.md](./notes-b.md) | 025~047 |
| [notes-c.md](./notes-c.md) | 048~070 |
| [notes-d.md](./notes-d.md) | 071~093 · ~3:50 |

각 프레임마다 다섯 가지를 같은 순서로 본다 — **군중 / 카메라 / 색 / 질감 / UI**.
매번 같은 것을 세야 프레임 사이를 비교할 수 있고, 그래야 「인상」이 아니라
**수치와 경향**이 남는다. 「본 것」과 「추정」을 문장 단위로 구분해 적었다.

## 이미지는 여기 없다

**프레임 이미지 자체는 저장소에 없다.** 원작 영상은 저작물이라 잘라 낸 정지화면도
같다 — 분석에만 쓰고, 저장소에는 **글로만** 옮긴다. 이 저장소가 `public/`의
에셋을 검사로 막는 것과 같은 규칙이다.

다시 뽑으려면 [grab.sh](./grab.sh)를 저장소 **밖에서** 돌린다. 스크립트가
`yt-dlp`로 받아 `ffmpeg`로 자른다(960px, 2.5초 간격).

## 이 기록이 무엇을 낳았나

여기서 나온 결론은 두 곳으로 갔다:

- **[DOKEV_VIDEO_STUDY.md](../DOKEV_VIDEO_STUDY.md) 「3.5 프레임에서 직접 확인한 것
  (2026-08-24)」** — 866줄을 요약한 것. 「원색은 배경이 아니라 악센트다」,
  「카메라가 대부분 멀다」, 「실사 배경과 만화 캐릭터를 잇는 중간 단계가 있다」,
  「군중은 수가 아니라 행동의 종류로 살아 있다」가 전부 여기서 나왔다.
- **[RALPH_BACKLOG.md](../RALPH_BACKLOG.md) 「프레임을 보고 순위를 고쳤다」** —
  기사만 읽고 세웠던 우선순위를 뒤집은 자리. 요약본이 아니라 **이 원본**이
  근거이므로, 판단을 되돌아볼 때는 여기를 읽는다.

요약본만 남기지 않고 원본을 함께 두는 이유: 요약은 이미 **무엇이 중요한지 정한
뒤**의 글이다. 다음에 다른 것이 중요해지면 요약에는 그 근거가 없다.
