> 분석 대상: 2021 Gamescom 공개분 **세 편** — ONL 게임플레이 트레일러,

## 1. 분석 결론

트레일러의 핵심 경험은 작은 동네에서 도깨비를 찾는 정적인 수집 체험이 아니다.

> 어린이 캐릭터가 넓고 화려한 현대 도시를 놀이터처럼 돌아다니며, 서로 다른 능력을 지닌 도깨비들과 이동·전투·놀이를 즐기는 고밀도 액션 어드벤처

### 핵심 키워드

- 어린이 주인공
- 활기찬 현대 도시
- 빠르고 다양한 이동
- 도깨비 소환과 협동
- 장난감 같은 액션
- 화려한 물리·파티클 반응
- 놀이와 생활 활동
- 음악, 춤, 축제

## 2. 캐릭터에 대한 정정

트레일러의 도깨비는 전통 설화에서 흔히 떠올리는 뿔 달린 괴물이나 하나의 공통 종족 디자인이 아니다.

- 로봇, 동물, 장난감, 인형, 정령처럼 서로 다른 형태를 가진다.
- 각 도깨비는 독립된 실루엣과 성격, 능력을 가진 동료로 보인다.
- 인간 어린이 캐릭터가 플레이의 중심에 있다.
- 도깨비는 이동·전투·놀이에 참여하는 동료 역할을 한다.

따라서 DokeV에서도 `일반적인 도깨비 캐릭터 한 마리`를 먼저 정의하지 않는다. 플레이 기능과 성격을 먼저 정한 뒤 그 기능에 맞는 독자적인 동료 캐릭터를 디자인한다.

## 3. 트레일러에서 직접 확인되는 기능

아래 항목은 2021 게임플레이 트레일러 화면에서 직접 확인되는 표현이다. 실제 출시 제품의 세부 사양이나 최종 기능 범위까지 보장하는 것은 아니다.

### 3.1 어린이 플레이어 캐릭터

- 여러 외형과 의상의 어린이 캐릭터
- 헤어, 모자, 상·하의, 신발, 가방
- 달리기, 점프, 회피, 전투
- 휴대용 기기를 보는 행동
- 춤과 포즈
- 여러 어린이 캐릭터가 함께 행동하는 장면

### 3.2 현대 도시와 자연 탐험

- 한국형 주택가
- 상업 지역과 광장
- 도로와 횡단보도
- 공원과 놀이터
- 전통 건축물
- 해안과 절벽
- 숲과 폭포
- 낮과 밤
- 차량과 시민이 움직이는 환경
- 어딘가로 이어지는 **포탈**에 들어가는 장면 (Extended 트레일러)

### 3.3 이동 수단과 이동 능력

- 걷기와 달리기
- 자전거
- 스케이트보드
- 롤러스케이트 계열 이동
- 로켓 또는 부스터 대시
- 우산을 이용한 활공
- 공중 줄을 잡는 스윙 이동
- 제트스키
- **동물 탑승** — 라마·알파카처럼 생긴 짐승 등에 타고 달린다. 도깨비를
  타는 것이 아니라 **아이가 탈 만한 짐승·장난감**을 탄다 (소형 자동차도 나온다)
- 자동차와 도로 교통

이동 자체가 단순한 목적지 도달 수단이 아니라 주요 놀이 요소로 표현된다.

### 3.4 실시간 액션 전투

- 캐릭터의 근접 공격
- 장난감 같은 원거리 무기
- 큰 망치 또는 둔기
- 회피와 대시
- 공중 공격
- 광역 공격
- 강한 컬러 파티클
- 피격 시 튕겨 나가는 반응
- 도시 오브젝트 주변에서 벌어지는 전투
- 여러 도깨비가 참여하는 전투
- **무기를 그 자리에서 변형·개조해** 다른 공격으로 바꾸는 장면 (펄어비스 보도자료)
- **장비 자체가 능력인 것** — 로켓 슈즈, 어깨 대포, 마법 모자
- 전투 중 **지형과 오브젝트가 부서지는** 표현 (펄어비스 보도자료)

전투는 무겁거나 잔인한 표현보다 장난감, 풍선, 색종이, 물감처럼 유쾌하고 과장된 표현을 사용한다.

### 3.5 도깨비 소환과 협동

- 전투 중 도깨비 등장
- 도깨비별로 다른 형태의 공격
- 플레이어 주변에서 동행
- 크기가 다른 여러 도깨비
- 도깨비가 직접 적과 충돌하거나 능력 사용
- 여러 동료가 한 전투에 참여
- **찾아서 포획하는 것 자체가 장르의 중심이다** — 공식 장르명이 「도깨비 수집
  오픈월드 액션 어드벤처」다. 만나는 것과 잡는 것은 다른 행동이다
- **도깨비가 플레이어와 함께 성장한다** (공식 사이트)
- 도깨비 능력으로 **길을 열거나 퍼즐을 푸는** 활용 (매체 정리)

도감이나 카드만으로 존재하는 수집물이 아니라 월드에서 함께 움직이고 행동하는 동료로 표현된다.

### 3.6 대형 적과 보스전

- 일반 적보다 큰 적
- 도심 한가운데의 대형 전투
- 여러 캐릭터와 도깨비가 동시에 공격
- 범위 공격
- 폭발, 전기, 충격파
- 차량과 도시 오브젝트가 있는 전장

보스전은 트레일러의 시각적 클라이맥스 역할을 한다.

### 3.7 놀이와 생활 활동

- 연날리기
- 춤 — 트레일러 전체가 **노래에 맞춘 뮤지컬 연출**이고, 시민과 다른 아이들이
  함께 추는 **군무**로 번진다. 혼자 추는 감정 표현과는 다른 장면이다
- **낚시**
- 친구들과 모이기
- 공원에서 놀기
- 휴대용 기기 사용
- 여러 탈것 타기
- 해안과 자연 감상
- 포즈와 감정 표현

도시는 전투용 맵에 그치지 않고 다양한 행동이 가능한 놀이 공간으로 표현된다.

### 3.8 물리와 환경 반응

- 전투 시 먼지와 파편
- 캐릭터와 적의 충격 반응
- 차량 주변 전투
- 물 위 제트스키 이동
- 풀과 나무의 움직임
- 날아가는 소품처럼 보이는 장면
- 계단과 경사 지형 이동

모든 환경의 파괴 가능 여부는 확인할 수 없지만, 충돌과 물리 반응은 중요한 시각 요소다.

## 4. 암시되지만 확정할 수 없는 기능

다음은 영상에 암시가 있으나 트레일러만으로 실제 시스템 여부와 범위를 확정하지 않는다.

- 온라인 멀티플레이
- 자유도 높은 캐릭터 커스터마이징
- 모든 차량의 직접 운전
- 모든 건물 내부 입장
- 완전한 환경 파괴
- 도깨비 **진화** — 「함께 성장한다」는 공식 설명이 있으나 진화·레벨 같은
  구체적 형태는 확정할 수 없다 (성장 자체는 3.5절로 옮겼다)
- 플레이어 간 거래
- 자유로운 NPC 대화
- 실시간 날씨 시스템

여러 캐릭터가 함께 등장하더라도 실제 사용자인지 NPC 동료인지 영상만으로 단정하지 않는다.

## 5. 트레일러의 경험 구조

트레일러에서 반복적으로 강조되는 경험을 다음과 같이 정리한다.

```text
도시 발견
→ 빠른 이동
→ 이상 현상 또는 적 조우
→ 도깨비 소환
→ 캐릭터와 도깨비의 협동 전투
→ 색상·파편·물리 반응이 터지는 결과
→ 춤, 놀이, 새로운 이동으로 전환
```

### 기존 기획과의 차이

```text
기존: 탐험 → 단서 수집 → 도깨비 발견 → 포토 모드

수정: 이동 → 조우 → 소환 → 액션 → 축제 같은 결과 → 놀이/공유
```

- [x] 자전거 — 킥보드·자전거·보드 3종. 거리 거치대에서 타고 내린다. 셋을

- [x] 여러 도깨비 동행 — 만난 도깨비가 모두 따라오고 능력 효과가 합쳐진다
- [x] 미니 보스 — 「고물 대장」. 예고 링을 보고 피한 뒤 빈틈에 때리는 리듬
- [x] 낮과 밤 — 시간대 4종, 밤에 창문·가로등·전조등이 켜진다
- [x] 시민 NPC — 보행자, 거리 컬링
- [x] 차량 교통 — 신호 대기 포함
- [x] 감정 표현 — 플레이어 3종(춤·손 흔들기·앉기) + 동료 mood 4종과 대사
- [x] 도감 — 해금 조건·진행률 표시

### 6.3 장기 검토 후보

전부 **미구현**이다. 웹 다운로드 예산과 1인 개발 규모에서 감당할 수 없다고 판단해
손대지 않았다 — 못 한 것이 아니라 하지 않기로 한 것이다.

- [ ] 제트스키 — **미구현**. 다만 물 위를 달리는 것 자체는 생겼다
      (`world/waterRide.ts`) — 탈것을 탄 채 수면 위로 나갈 수 있다.
      전용 제트스키 모델과 물살 연출은 없다
- [ ] 자동차 운전 — 주행 차량은 배경으로만 있고 탈 수 없다
- [ ] 대형 보스 — 미니 보스(「고물 대장」)까지만 왔다
- [ ] 실시간 멀티플레이
- [ ] 넓은 오픈월드
- [ ] 다수의 실내 공간
- [ ] 고급 물리 파괴

### 6.4 v0.2에서 새로 목록에 올린 것

3절을 넓히면서 드러난, **후보에조차 없던 기능들**이다. 전부 미구현이고, 아래
순서는 "웹에서 값이 큰 순서"로 정한 우선순위다.

| 기능 | 근거 | 판단 |
|---|---|---|
| **무기 종류** — 큰 망치 | 3.4 | **했다.** 「장난감 방망이」와 「고무 망치」 두 자루, Q로 바꾼다. 망치는 느리고 넓고 한 방이다 |
| **무기 종류** — 원거리 장난감 무기 | 3.4 | **했다.** 「딱총」. 바라보는 쪽으로 탄이 나가고 로봇과 대장 모두에 닿는다. 자동 조준은 없다 |
| **탈 것 — 짐승과 장난감** | 3.3 | **했다.** 「조랑말」(자연 구역 풀밭)과 「장난감 자동차」(거리 거치대). 조랑말은 제일 느리지만 잘 서고 잘 돌며 **다리가 움직인다** — 자연 구역에 탈 것이 아예 없던 문제도 함께 풀렸다 |
| **도깨비 능력으로 여는 길** (퍼즐) | 3.5 | **했다.** 「빛으로 여는 문」 셋. 동료 빛이 닿으면 열리고, 요구 밝기가 달라 누구와 다니느냐로 열리는 문이 갈린다 |
| **도깨비 포획** — 만나는 것과 잡는 것의 분리 | 3.5 | **일부.** 조건을 채우면 자리가 드러나고 **그 자리에서 눌러야** 만나진다(`roster.projectDiscovery`). 반경에 들어가기만 하면 되던 것은 고쳤다. 「잡는」 행위 자체는 여전히 없다 |
| **도깨비 성장** | 3.5 | 검토. 저장 포맷이 늘어난다 |

## 7. 추천 첫 번째 플레이 장면

기존의 단서 수집형 첫 퀘스트 대신 다음 장면을 우선 검토한다.

```text
도시 광장에서 어린이 캐릭터로 시작
→ 스케이트보드를 타고 거리를 질주
→ 이상 현상으로 장난감 로봇들이 등장
→ 도깨비 동료를 소환
→ 장난감 무기와 도깨비 능력으로 전투
→ 승리하면 광장에 색종이와 물감 효과
→ 도깨비와 함께 춤 또는 사진 촬영
```

### 목표

- 플레이 시간: 3~5분
- 작은 공간 안에서 이동, 소환, 전투, 결과 연출을 모두 체험
- 트레일러의 역동성과 밝은 분위기를 짧게 전달
- 데스크톱과 모바일에서 동일한 플레이 루프 검증

## 8. 필요한 3D 에셋과 GLB

> **이 절과 9절은 채택하지 않은 계획이다.** 초기 다운로드 예산 때문에 GLB를

> 합성, 사운드는 Web Audio 합성이다. 아래 목록은 "이런 형태가 필요하다"는

>
> 이 절을 지우지 않는 이유: 무엇을 만들어야 하는지에 대한 판단은 여전히
> 유효하고, 나중에 예산이 달라지면 다시 볼 문서이기 때문이다.

## 9. GLB 제작 우선순위

첫 GLB를 도깨비 한 마리로 임의 제작하지 않는다. 웹 플레이 장면을 검증할 수 있는 순서로 제작한다.

1. 어린이 플레이어 블록아웃
2. 스케이트보드
3. 장난감 로봇 기본형
4. 지원형 도깨비 블록아웃
5. 전투형 도깨비 블록아웃
6. 광장 환경 모듈
7. 애니메이션과 이펙트
8. 최종 모델·재질·텍스처

### 제작 원칙

- `.blend`를 수정 원본으로 관리한다.
- `.glb`는 웹 배포본으로 생성한다.
- 원작 캐릭터의 외형을 그대로 복제하지 않는다.
- 기능, 실루엣, 색상 언어는 프로젝트 고유의 기준을 만든다.
- Blender 렌더가 아니라 실제 웹 장면에서 최종 승인한다.

## 11. 기능 판단 원칙

트레일러 분석 결과를 프로젝트 기능으로 옮길 때 다음 표시를 사용한다.

- `확인`: 영상 또는 공식 설명에서 직접 확인됨
- `추정`: 연출상 가능성이 있으나 시스템 여부가 불명확함
- `프로젝트 결정`: 원작과 관계없이 DokeV에 도입하기로 결정함
- `제외`: 범위, 성능, IP 문제로 도입하지 않음

원작 영상에 등장한다는 이유만으로 모든 기능을 프로젝트에 포함하지 않는다. 웹에서 짧고 완성도 높은 경험을 제공하는 데 필요한 기능만 선택한다.
